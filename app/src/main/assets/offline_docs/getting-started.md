# 快速开始

## 适用场景

第一次安装 Metric，或者清除 App 数据后重新配置时，按这一页操作。

## 第一步：完成首次引导

首次打开 App 后，会依次完成：

1. 介绍页。
2. 启动服务页。
3. 校准页。

校准页是最后一步，没有单独的“完成”页面。  
完成后，如果 Metric Daemon 已连接，会进入主界面；如果没有连接，会进入激活页。

## 第二步：启动 Metric Daemon

在启动服务页或激活页中，选择一种方式启动：

- Root 启动：适合已 Root 且已给 Metric 授权的设备。
- Shell 命令启动：适合通过 ADB Shell 或设备本地终端启动。

> [!NOTE]
> Shell 命令请复制 App 页面显示的内容。命令里包含当前安装包的 native library 路径，不建议手动猜路径。

## 第三步：确认连接状态

启动后看页面上的服务状态：

- 已连接：可以继续进入首页或校准页。
- 未连接：说明 Daemon 还没有把 Binder 推回 App。
- 启动失败：按错误提示重新授权或改用 Shell 启动。

如果刚执行完 Shell 命令，可以等待几秒再回到 App。  
如果仍未连接，先看 [排查问题](troubleshooting.md)。

## 第四步：完成校准

服务连接后，首次引导会进入校准页。建议按顺序处理：

1. 拔掉充电器，让设备进入放电状态。
2. 等待自动探测电流倍率。
3. 判断是否需要开启串联双电芯。
4. 自动探测完成后，再决定是否手动调整校准。

如果设备无法进入可探测状态，可以跳过自动探测，然后手动校准。  
校准细节见 [电池与功率校准](calibration.md)。

## 第五步：检查首页

进入首页后，先确认这些区域是否有数据：

- 内存卡片。
- GPU 卡片。
- CPU 聚合卡片。
- CPU 占用最高的进程列表。

> [!NOTE]
> 部分指标显示 `--` 或不可用时，不一定代表 App 故障。不同设备、权限和内核节点会影响可读取的数据范围。
