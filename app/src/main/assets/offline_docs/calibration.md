# 电池与功率校准

## 什么时候看这一页

遇到下面任一情况，先处理校准：

- 首次使用 Metric。
- Power 长期为 `0.00W`。
- 充电和放电方向相反。
- 功率明显偏大或偏小。
- 双电芯设备的功率看起来只有预期的一半。
- FPS 记录详情中的 Power 曲线明显不可信。

## 校准入口

- 首次引导的校准页：第一次使用时完成基础校准。
- 设置页 > Battery：后续重新调整校准。

## 校准影响哪些数据

电流校准和串联双电芯会影响所有基于 Power 的展示：

- 首页功率相关数据。
- 负载监视器中的 Power。
- FPS 记录详情中的 Power 曲线。
- 后续基于功率的统计结果。

> [!NOTE]
> 如果 Power 基础口径不对，后续分析也会不可靠。

## 自动探测怎么用

自动探测用于推断电流倍率。

推荐操作：

1. 启动 Metric Daemon。
2. 拔掉充电器。
3. 保持设备处于放电状态。
4. 等待页面显示自动探测完成。

> [!NOTE]
> 自动探测期间，不建议反复切换充电状态。如果设备状态一直无法满足要求，可以跳过自动探测后手动调整。

## 自动探测状态含义

- 请先启动服务：Daemon 未连接。回到启动页或激活页启动服务。
- 请移除充电器：当前仍在充电。拔掉充电器。
- 等待设备进入放电状态：系统还没有报告放电。等待，或检查设备状态是否异常。
- 正在探测电流倍率：正在收集稳定样本。保持当前状态，不要频繁切换负载。
- 自动探测已完成：已应用探测结果。检查 Power 是否合理。
- 已跳过自动探测：用户跳过了探测。手动调整校准倍率。

## 串联双电芯

串联双电芯用于修正双电芯设备的功率显示。

建议判断方式：

1. 先完成电流倍率自动探测。
2. 在高负载场景观察 Power。
3. 开启串联双电芯后再次观察。
4. 选择更接近真实设备功耗的状态。

不要只根据商品宣传决定是否开启。  
最终以 Metric 显示的功率是否合理为准。

## 手动电流校准

手动校准用于处理自动探测不适用的设备。

适合情况：

- 自动探测无法完成。
- 探测完成后功率仍明显异常。
- 设备电流节点单位和常见设备不同。
- 充放电方向需要修正。

调整时建议一次只改一个方向或倍率，然后回到首页或悬浮窗观察 Power。  
不要在充电、放电、负载剧烈变化时连续调整多个值。

## 校准后怎么验收

可以用下面方式快速判断：

- 放电时，Power 应表现为放电方向。
- 充电时，Power 应表现为充电方向。
- 待机轻负载不应长期显示极端大功率。
- 高负载时，Power 应随 CPU/GPU 负载上升。
- FPS 记录详情里的 Power 曲线应和实际负载变化大致一致。

如果这些条件都不满足，优先重新检查自动探测、串联双电芯和手动倍率。
